Плагин — обычный JS-модуль: export default function install(api) { ... }. У api есть прямой доступ к DOM читалки (api.dom.reader, api.dom.dialogueBox...), api.addButton(...), api.getVar/setVar, api.on('nodeLoad'|'lineRender'|'beforeAdvance'|'choiceShown', cb) и api.registerStatement('ключ', { oneShot(args,api), mount(args,api)→cleanupFn }) — под свои plugin/widget в сценарии.
▼
Перетащи персонажа — задаёшь позицию. Ползунок под ним — размер. Если персонажа нет на сцене — сначала добавь его через show в тексте.
